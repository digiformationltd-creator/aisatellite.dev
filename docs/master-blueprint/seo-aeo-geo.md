### 1. TECHNICAL SEO FOUNDATION
- **Canonical Lock:** `https://aisatellite.dev` strictly enforced across all 194 routes.
- **Sitemap Architecture:** Dynamic `sitemap-index.xml` pre-rendered via `@astrojs/sitemap`. Automatically filters out private administrative routes (`/admin`, `/workspace`, `/launch-admin`, etc.).
- **Robots.txt Directives:** Configured in `public/robots.txt` allowing public indexing while disallowing `/admin`, `/workspace`, `/api/`, and private moderation consoles.

### 2. ANSWER ENGINE OPTIMIZATION (AEO)
To provide instant direct answers for Google Featured Snippets, Bing Copilot, and conversational interfaces:
- **Direct Answer Summaries:** Every software profile and comparison begins with a concise 2-sentence summary outlining what the tool does, whether it is permanently free, and who it is best suited for.
- **Structured Code Examples:** Shell commands, configuration blocks, and API calls are isolated in semantic `<pre><code>` blocks with copy buttons.
- **Troubleshooting Format:** Errors are formatted with Symptom $\to$ Root Cause $\to$ Verified Resolution steps.

---

### 3. GENERATIVE ENGINE OPTIMIZATION (GEO)
To maximize citation accuracy and relevance in LLM-powered search engines (Perplexity, ChatGPT Search, Gemini):
- **Schema.org Structured Data:** Uses `SoftwareApplication`, `TechArticle`, `BreadcrumbList`, and `Organization` types with explicit `license`, `operatingSystem`, and `applicationCategory`.
- **Authoritative Timestamps:** Every technical guide displays `dateModified` and `verifiedBy` metadata to prevent AI models from citing outdated software versions.
- **Entity Disambiguation:** Tools are explicitly linked to their primary repository, creator organization, and commercial target via knowledge graph edge metadata.
